# Ease Calculator

A polished, native SwiftUI calculator for iPhone and iPad. It includes standard arithmetic, decimal input, percentages, sign toggling, clear, divide-by-zero handling, and accessible controls.

## Open and run

Open `EaseCalculator.xcodeproj` in Xcode 15 or newer, select an iOS simulator, and run the `EaseCalculator` scheme. The app targets iOS 17+.
